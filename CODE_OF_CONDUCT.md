# Code of Conduct

Refocal adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for all project spaces: issues, pull requests, discussions and reviews.

In short: be welcoming and respectful, accept constructive criticism, focus on what is best for
the people who use Refocal. Harassment, insults, sexualised language or imagery, and publishing
others' private information are not acceptable.

Report unacceptable behaviour privately to the maintainers listed in
[GOVERNANCE.md](GOVERNANCE.md) (GitHub: @sleepe229). Reports are reviewed promptly and kept
confidential. Enforcement follows the Covenant's guidelines: correction, warning, temporary ban,
permanent ban.
