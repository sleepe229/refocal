# 16. Глоссарий

| Термин | Определение |
|---|---|
| **ANE** | Apple Neural Engine — нейросетевой ускоритель в чипах Apple, доступен через Core ML |
| **Auto** | Режим, автоматически выбирающий параметры по анализу фото (детерминированные правила) |
| **Backend (бэкенд)** | Реализация `InferenceBackend`: ncnn Vulkan, ncnn CPU, Core ML, ORT QNN |
| **Band (полоса)** | Горизонтальная полоса выходного изображения, соответствующая одному ряду тайлов |
| **BandStore** | Хранилище полос выхода на диске; основа checkpoint/resume и экспорта |
| **Blocklist** | Список пар (GPU/драйвер, модель), для которых GPU-бэкенд запрещён |
| **C2PA** | Стандарт криптографически подписанных манифестов происхождения контента |
| **Checkpoint** | Состояние джоба (`checkpoint.json`) для возобновления с последней полосы |
| **CodeFormer** | Модель восстановления лиц с параметром fidelity (S-Lab NC) |
| **Compact** | Модель `realesr-general-x4v3` (SRVGGNetCompact), SR по умолчанию |
| **Crash sentinel** | Маркер, обнаруживающий падение нативного GPU-кода при следующем запуске |
| **DNI** | Deep Network Interpolation — интерполяция весов двух моделей (уровни денойза) |
| **`.rfpack`** | Файл офлайн-пака: zip с подписанным манифестом и файлами модели |
| **Feather** | Плавное смешивание на границах (тайлов, масок лиц) |
| **FFHQ** | Датасет лиц Flickr-Faces-HQ (CC BY-NC-SA); также шаблон выравнивания 512×512 |
| **FGS** | Foreground service (Android) — фоновая работа с видимым уведомлением |
| **Fidelity (w)** | Параметр CodeFormer: 0 — качество, 1 — сходство с входом |
| **GFPGAN** | Модель восстановления лиц на основе генеративного приора StyleGAN2 |
| **Golden-набор** | Фиксированный набор изображений и эталонных выходов для регрессионных тестов |
| **Inbox** | Внутреннее хранилище копий входных фото |
| **Jetsam** | Механизм iOS, завершающий процессы при нехватке памяти |
| **Job (джоб)** | Одна задача обработки одного изображения по рецепту |
| **LMK** | Low Memory Killer (Android) |
| **LPIPS** | Перцептивная метрика различия изображений |
| **Manifest (манифест)** | Подписанный JSON со списком паков, файлов, хэшей, лицензий |
| **minisign** | Инструмент/формат подписей Ed25519 |
| **NC** | Non-commercial — лицензии, запрещающие коммерческое использование |
| **ncnn** | Фреймворк инференса Tencent с поддержкой Vulkan |
| **NR-IQA** | No-reference image quality assessment — оценка качества без эталона (MUSIQ, CLIP-IQA…) |
| **Pad (паддинг)** | Дополнительные пиксели вокруг тайла, обрезаемые после инференса |
| **Pack (пак)** | Версионированная единица поставки модели |
| **Pigeon** | Генератор типобезопасных платформенных каналов Flutter |
| **Pyramid (пирамида)** | Набор тайлов результата на нескольких уровнях масштаба для просмотрщика |
| **PSNR** | Peak signal-to-noise ratio — метрика различия изображений, дБ |
| **Recipe (рецепт)** | Сериализованный `EnhanceRequest`: все параметры обработки |
| **SR** | Super-resolution — увеличение разрешения |
| **Strength** | Сила эффекта: смешивание результата с Lanczos-апскейлом оригинала |
| **Tier (тир)** | Класс устройства T0/T1/T2, определяющий модели, тайлы и лимиты |
| **Tile (тайл)** | Фрагмент входа фиксированного размера, обрабатываемый моделью за раз |
| **YuNet** | Лёгкий детектор лиц (MIT) из OpenCV Zoo |
