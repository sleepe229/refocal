# 06. UX/UI

## 1. Принципы UX

1. **Три тапа до результата:** выбрать → (Auto) → сохранить.
2. **Прозрачность:** видно, что делает ИИ, какой моделью, сколько осталось, почему снижено качество.
3. **Контроль без перегруза:** базовые ползунки на виду, продвинутое — в раскрывающейся панели.
4. **Честный язык:** никогда «оригинал», «восстановленное фото» для результата; формулировки «улучшено ИИ», «интерпретация».
5. **Не теряем работу:** отмена и возврат — безопасны; прогресс восстанавливается.

## 2. Карта экранов и маршрутов (go_router)

| Маршрут | Экран | Назначение |
|---|---|---|
| `/` | Home | Кнопка «Выбрать фото», последние результаты, вход в очередь |
| `/onboarding` | Onboarding | 2–3 экрана при первом запуске |
| `/editor/:sessionId` | Editor | Превью, режимы, параметры, «Обработать» |
| `/editor/:sessionId/result` | Result/Compare | Сравнение, экспорт, «Сообщить о проблеме» |
| `/queue` | Queue | Очередь пакетной обработки |
| `/history` | History | Рецепты и превью |
| `/models` | Models | Установленные и доступные паки |
| `/models/:packId` | Pack details | Описание, лицензия, размер, скачать/удалить |
| `/settings` | Settings | Экспорт, метаданные, производительность, хранилище, сеть, язык |
| `/settings/about` | About | Версия, лицензии, приватность, предупреждение об ИИ, исходники |
| `/import` | (deep link) | Приём из share → Editor или Queue |

На планшетах и foldable (ширина ≥ 840 dp) — двухпанельный макет: список (история/очередь) + редактор; `NavigationRail` вместо нижней навигации.

## 3. Ключевые потоки

### 3.1 Первый запуск

```
Splash → Onboarding (1: «Всё на устройстве», 2: «ИИ может менять детали», 3: «Сравнение»)
       → Home; в фоне — бенчмарк (FR-ONB-002), без блокировки UI
       → (опц.) карточка «Скачайте модель лиц для портретов» (FR-ONB-003)
```

### 3.2 Обработка одного фото

```
Home → [Системный пикер] → Editor: превью + чипы режимов (Auto выбран)
     → Auto-объяснение («4×, 2 лица, денойз средний») → [Обработать]
     → Прогресс (стадия, %, ETA, бэкенд; Отмена/Пауза)
     → Result: слайдер сравнения → [Сохранить] / [Поделиться] / [Ещё раз с другими настройками]
```

### 3.3 Режим «Лица» без пака

```
Editor → чип «Лица» → Sheet: «Нужна модель (170 МБ). Лицензия: некоммерческое использование.»
       → [Читать лицензию] → [Принять и скачать] → прогресс скачивания (можно свернуть)
       → по готовности режим доступен
```

### 3.4 Пакет

```
Home → пикер (мультивыбор) → Batch sheet: пресет, формат, автосохранение
     → Queue (список с прогрессом); Android — уведомление FGS; iOS — баннер «Обработка на паузе в фоне»
     → Итог: «Готово 28, ошибок 2» → [Показать ошибки]
```

### 3.5 Деградация и ошибки

| Ситуация | UI |
|---|---|
| Тайл уменьшен / бэкенд сменён | Неблокирующий баннер: «Обработка переключена на CPU — будет медленнее» + «Подробнее» |
| Требуется понизить масштаб | Диалог: «Недостаточно памяти для 4×. Обработать в 2×?» [2×] [Только лица] [Отмена] |
| Вход больше лимита тира | Диалог с вариантами (FR-IMP-006) |
| Нет места | Диалог: «Нужно ещё 420 МБ свободного места» [Очистить кэш] [Отмена] |
| Ошибка | Экран ошибки: понятное сообщение, код, [Повторить] [Сообщить] |
| Предыдущий запуск упал на GPU | Баннер при старте: «Похоже, графический драйвер нестабилен — включён CPU-режим» |

## 4. Состояния экранов

Каждый экран описывает состояния: `empty`, `loading`, `content`, `progress`, `error`, `offline` (для Models). Пример для Models:

| Состояние | Отображение |
|---|---|
| empty (нет сети, нет кэша манифеста) | «Список моделей недоступен без интернета. Можно импортировать файл .rfpack» [Импорт] |
| loading | Скелетоны карточек |
| content | Карточки паков: название, размер, лицензия (бейдж NC), совместимость с тиром, статус |
| progress | Прогресс-бар, [Пауза] [Отмена] |
| error | «Не удалось проверить подпись» / «Сеть недоступна» + [Повторить] |

## 5. Компонент сравнения (CompareViewer)

- Источники: превью ≤ 2048 + пирамида тайлов 256 px результата; для оригинала — даунскейл входа + тайлы входа, масштабированные к координатам результата.
- Режимы: слайдер (вертикальная граница, перетаскивание), удержание = оригинал, кнопка «Показать оригинал» (toggle), side-by-side.
- Зум: пинч до 1:1 пикселей результата (до 4:1 с nearest), синхронный в side-by-side; двойной тап — 1:1 / вписать.
- Лупа: долгое нажатие — круг 2× под пальцем (Could).
- Рамки лиц (в Editor): тап — вкл/выкл лицо (FR-FACE-007).
- Производительность: подгрузка только видимых тайлов, LRU-кэш тайлов в пределах `imageCache` тира, 60 fps (NFR-PERF-010).

## 7. Визуальный дизайн

- Material 3 (Android) с адаптивными элементами Cupertino на iOS там, где ожидается нативное поведение (диалоги, share, pickers — системные).
- Дизайн-токены в `ui_kit`: цвета (light/dark, контраст ≥ 4.5:1), типографика (масштабируемая), отступы 4/8/12/16/24, радиусы, длительности анимаций.
- Тёмная тема — по системной настройке; переключение в настройках.
- Edge-to-edge на Android 15+ (target 36): корректные insets, жесты навигации.
- Иконка, цвета, голос бренда — [appendix/brand.md](appendix/brand.md); токены `ui_kit` берут значения оттуда.

## 9. Локализация

- `gen_l10n` + ARB, ключи в `snake_case`, описание контекста для каждого ключа (`@key.description`).
- Плюрализация ICU (`{count, plural, one{…} few{…} many{…} other{…}}`) — русский требует форм one/few/many.
- RTL: `Directionality`, зеркальные иконки, проверка на псевдолокали (R0.5).
- Weblate (бесплатный хостинг для libre-проектов) — с R0.5; языки на старте — en, ru (Q-08).
- Тексты лицензий моделей не переводятся (юридически значимы), к ним даётся переведённое резюме.
