# ADR-0008: Navigation: go_router

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Deep links (`/import` из share), адаптивные макеты для планшетов.

## Решение

go_router с типизированными маршрутами и ShellRoute для адаптивной навигации.

## Последствия

(+) Deep links из коробки. (−) Зависимость от пакета Flutter team (приемлемо).

## Отклонённые альтернативы

- Navigator 2.0 вручную: дорого. auto_route: кодогенерация ради малого.
