# ADR-0022: Face models: licensing and safe defaults

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Нет permissive face-restoration моделей уровня GFPGAN: GFPGAN включает NC-компоненты (NVIDIA StyleGAN2, DFDNet) и обучен на FFHQ (CC BY-NC-SA); CodeFormer — S-Lab NC. Восстановление лиц рискует «подменить» лицо.

## Решение

- Face-модели не встраиваются и не хранятся в основном репозитории; поставляются паками с собственной лицензией и явным согласием.
- Встроенные модели — только permissive.
- `faceStrength` по умолчанию 0.5; предупреждение при первом использовании; CI-гейт ArcFace cos ≥ 0.95; лица > 512 px — ослабление.
- R2.0: исследование clean-room permissive face-модели.

## Последствия

(+) Лицензионная чистота приложения, честность. (−) Пользователь должен скачать ~170 МБ и принять лицензию для главной «фишки».

## Отклонённые альтернативы

- Встроить GFPGAN в APK: NC в сторах, F-Droid NonFreeAssets. - Отказаться от лиц: теряется основная ценность.
