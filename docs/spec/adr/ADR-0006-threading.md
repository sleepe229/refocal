# ADR-0006: Threading model

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Инференс длится секунды–минуты; UI не должен тормозить; отмена должна быть быстрой.

## Решение

Один `enh-worker` поток на активный джоб; внутри конвейер `prep (CPU) → infer (GPU/ANE) → post (бленд/запись)` с очередями глубиной 2 тайла. Одновременно один GPU-джоб. Отмена/пауза — атомарные флаги на границе тайла; целевая задержка ≤ 1 тайл (≤ 1 с на T1). Dart-изоляты для пикселей не используются.

## Последствия

(+) Предсказуемая память и латентность отмены. (−) Нет параллелизма между джобами (сознательно: GPU и память — узкое место).

## Отклонённые альтернативы

- Пул джобов: конкуренция за GPU и память, рост пика.
- Изоляты: см. ADR-0005.
