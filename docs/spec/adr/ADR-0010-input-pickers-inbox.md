# ADR-0010: System pickers and inbox copies

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Политика Play (с 05.2025) запрещает широкий доступ к медиа для таких приложений; URI пикеров могут истечь, а фону и очереди нужен стабильный файл.

## Решение

- Ввод только через Android Photo Picker (fallback `ACTION_OPEN_DOCUMENT`) и iOS PHPicker — без разрешений на чтение.
- Выбранный файл копируется в `AppSupport/inbox/` (дедуп по SHA-256). Квота по умолчанию 1 ГБ / 7 дней, очистка после экспорта, если не включено «Хранить для повторной обработки».

## Последствия

(+) Соответствие политикам, устойчивость очереди. (−) Дополнительное место и I/O.

## Отклонённые альтернативы

- `READ_MEDIA_IMAGES`: отклоняется политикой Play. - Работа по URI без копии: ломается в фоне.
