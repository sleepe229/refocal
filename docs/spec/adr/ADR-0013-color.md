# ADR-0013: Color management

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Модели обучены на gamma-encoded sRGB; фото бывают Display P3, 16-бит, HDR.

## Решение

Обработка в исходном кодировании без линеаризации; исходный ICC (в т. ч. P3) встраивается в результат. 16-бит → 8-бит. HDR gain map в 1.x отбрасывается с уведомлением (поддержка — R2.0). Альфа масштабируется Lanczos отдельно.

## Последствия

(+) Совпадение с распределением обучения. (−) Потеря HDR до 2.0.

## Отклонённые альтернативы

- Конверсия в sRGB: потеря гаммы P3. - Линейный свет: не соответствует обучению моделей.
