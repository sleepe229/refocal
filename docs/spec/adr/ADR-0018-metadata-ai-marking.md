# ADR-0018: Metadata and AI marking

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Нужно сохранить полезные метаданные, защитить приватность и честно маркировать результат ИИ.

## Решение

- EXIF-ориентация запекается (`Orientation=1`); дата, камера, ICC сохраняются; размеры обновляются; EXIF-миниатюра удаляется.
- GPS удаляется по умолчанию при share и при сохранении (настраивается).
- XMP: `Iptc4xmpExt:DigitalSourceType = …/compositeWithTrainedAlgorithmicMedia`, `xmp:CreatorTool`. Включено по умолчанию, отключаемо с предупреждением.
- C2PA (R1.4; перенесено с R1.3 2026-10-21) через c2pa-rs: самоподписанный ключ на устройстве; UI честно сообщает, что подпись «недоверенная».

## Последствия

(+) Прозрачность, соответствие IPTC и духу EU AI Act ст. 50. (−) Rust-тулчейн для C2PA.

## Отклонённые альтернативы

- Не маркировать: противоречит принципам. - exiv2: GPL.
