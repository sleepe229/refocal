# ADR-0021: Crypto in native core

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Нужны SHA-256 файлов до ~190 МБ и проверка Ed25519-подписей minisign на обеих платформах.

## Решение

Monocypher (CC0/BSD-2) + собственная реализация формата minisign в native core; функции `enh_verify_file`, `enh_verify_minisign`.

## Последствия

(+) Быстро, одна реализация. (−) Своя обвязка формата minisign — покрывается тестами с эталонными векторами.

## Отклонённые альтернативы

- Dart-пакеты crypto: медленно на больших файлах. - Платформенные API: две реализации.
