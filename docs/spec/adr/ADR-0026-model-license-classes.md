# ADR-0026: Классы лицензий моделей и расширение без замены

- **Статус:** Accepted
- **Дата:** 2026-10-21
- **Дополняет:** [ADR-0022](ADR-0022-face-models-licensing-defaults.md)

## Контекст

Модели в приложении — поколения 2021–2023 годов: Real-ESRGAN, GFPGAN 1.4, CodeFormer. Разрыв в качестве с облачными конкурентами — риск R15.

Исследование 2026-10-21 (04 §1, «Источники кандидатов») показало:

- Самые сильные компактные SR-модели для реальных фото выпускает сообщество (OpenModelDB, Phhofm и другие). Почти все они под **CC-BY-4.0**: коммерческое использование разрешено, нужна атрибуция. Под Apache-2.0 нашлась одна: 2xPublic_realplksr_dysample_layernorm_real.
- У многих моделей с permissive-кодом **лицензия весов не указана**: RestoreFormer++, VQFR, SCUNet, DRUNet, NAFNet, Restormer.
- Одношаговая диффузия для лиц выходит либо под NC (OSDFace, InterLCM), либо под MIT, но требует своего ядра (PMRF).

ADR-0022 разрешает встраивать только permissive-модели, а NC — только паком с согласием. CC-BY и «веса без лицензии» он не описывает.

## Решение

1. **Расширение, а не замена.** Новая модель добавляется паком рядом с текущими.
   - `sr.general-x4v3` остаётся встроенной моделью по умолчанию и fallback.
   - Паки GFPGAN, CodeFormer, x4plus, anime и «старого фото» не снимаются.
   - Auto выбирает новую модель только в категориях golden-набора, где `sr_eval.py` или `bias_eval.py` показали выигрыш. Прежняя модель остаётся в «Настроить».
2. **Классы лицензий весов:**

   | Класс | Лицензии | Поставка |
   |---|---|---|
   | Permissive | MIT, BSD, Apache-2.0, CC0 | встроена или пак без согласия |
   | Attribution | CC-BY-4.0 | только пак, **без экрана согласия**; атрибуция (автор, ссылка, лицензия) — в MODELS.md, в «О приложении» → лицензии и в строке модели на экране моделей |
   | Non-commercial | CC-BY-NC(-SA), S-Lab, GFPGAN NC, OSDFace academic и т. п. | только пак с согласием (ADR-0022) |
   | Не указана | веса без лицензии при открытом коде | **не публикуется**, пока автор письменно не подтвердит лицензию (ответ хранится в `docs/ml/licenses/`), или после собственного переобучения |
   | ShareAlike (CC-BY-SA) | CC-BY-SA-4.0 | как Attribution; производные веса (дообучение) — под той же лицензией |

3. **Встроенные модели** — только класс Permissive, как в ADR-0022 и ML-REG-003.
4. **Генеративные модели лиц** (одношаговая диффузия, R1.5) — только паком:
   - только явное включение пользователем, **никогда не Auto**;
   - отдельное предупреждение об изменении черт лица;
   - тот же ArcFace-гейт по подгруппам, что у CodeFormer (ADR-0022, ML-BIAS-001);
   - AI-маркер обязателен.

## Последствия

(+) Качество можно поднимать сразу, без собственного переобучения (R2.0). У пользователя остаётся прежняя модель. Лицензии прозрачны.

(−) Растёт число паков и матрица тестов. CC-BY требует атрибуции в трёх местах. Для «веса без лицензии» нужна переписка с авторами, и пак может так и не выйти. Схема манифеста и `check_manifest.py` должны знать класс лицензии (поле `license.class`).

## Отклонённые альтернативы

- Встраивать CC-BY-модели в APK: растёт APK, а атрибуцию сложнее показать.
- Экран согласия для CC-BY: лишний вопрос пользователю (06 §1) при лицензии, которая этого не требует.
- Заменить `general-x4v3` новой моделью: нет доказательства выигрыша на всех категориях, теряется встроенный permissive-fallback.
- Публиковать веса без лицензии «по умолчанию permissive»: без лицензии прав на распространение нет.
