# ADR-0023: Mobile graph rewrite for StyleGAN2-based face models

- **Статус:** Accepted
- **Дата:** 2026-10-09
- **Основание:** [Спайк S1](../../spikes/S1.md)

## Контекст

GFPGAN (и другие модели с декодером StyleGAN2) использует модулированную свёртку: веса умножаются на стиль `s` во время инференса и демодулируются через `rsqrt(Σ W²s²)`. В S1 выяснилось:

1. `s²` и `Σ W²s²` достигают ~10⁶ при пределе fp16 65504. Получается `rsqrt(inf) = 0`, выход тихо обнуляется: PSNR 9 дБ, NaN нет. Ломается на любом fp16-рантайме: ncnn Vulkan, ARM CPU fp16, Core ML/ANE, CUDA fp16.
2. Свёртки с динамическими весами (23 шт.) не поддерживаются быстрыми путями ncnn Vulkan и ANE: они уходят на CPU, это ×22 медленнее и +1.4 ГБ памяти.

## Решение

Перед экспортом все `ModulatedConv2d` с демодуляцией заменяются эквивалентом (batch = 1):

```
s ← s / max|s|
y = conv(x · s, W) · rsqrt(Wsq · s² + ε),   Wsq[o,i] = Σ_k W[o,i,k]²  (константа)
```

- Применяется в `ml/convert` для всех паков с декодером StyleGAN2 (GFPGAN; для CodeFormer — проверить в S1c).
- Конверсия в ncnn идёт через ONNX (`pnnx model.onnx`): pnnx падает на TorchScript перезаписанной модели.
- Гейты CI для таких паков:
  - выход перезаписанной модели против оригинала в fp32: max|Δ| ≤ 1e-4;
  - прогон в чистом fp16 (CUDA или CPU-эмуляция): PSNR ≥ 35 дБ к эталону;
  - число свёрток с неконстантными весами в итоговом графе = 0.

## Последствия

(+) fp16 на всех бэкендах (ncnn Vulkan fp16 — PSNR 48.8–51.4 дБ), обычные свёртки на GPU/ANE, ×22 быстрее на дискретном GPU, −1.4 ГБ памяти, ncnn-пак 177 МБ вместо 219 МБ.
(−) Своя модификация upstream-архитектуры: её нужно поддерживать и покрыть тестами эквивалентности. Batch > 1 не поддерживается (не нужен: лица обрабатываются по одному).

## Отклонённые альтернативы

- fp32 для «проблемных слоёв» (mixed precision): переполняется вся цепочка в 15 слоях, а динамические веса остаются, так что скорость и память не решаются.
- Только fp32 на всех бэкендах: на мобильных GPU ×2 медленнее, ANE недоступен.
- Отказ от GFPGAN: теряется основная функция; альтернатив той же лицензионной категории без этой архитектуры нет.
