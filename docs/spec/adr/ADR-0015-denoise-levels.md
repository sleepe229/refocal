# ADR-0015: Discrete denoise levels

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

`realesr-general-x4v3` поддерживает силу денойза через интерполяцию весов (DNI); скомпилированный mlmodelc нельзя интерполировать в рантайме.

## Решение

Дискретные уровни {0, 0.5, 1.0}, запечённые офлайн. Уровень 0.5 встроен, 0 и 1.0 — пак «Compact+» (~5 МБ).

## Поправка (2026-10-15, 0.2)

«Compact+» — два пака в манифесте, `sr.general-x4v3-dn0` и `sr.general-x4v3-dn100` (~2.4 МБ каждый, по схеме манифеста пак — одна модель, ядро ищет `<id>/model.ncnn.*`); уровень выбирается в редакторе, когда установлен хотя бы один.

## Поправка (2026-10-21)

Уровень 0 встроен в приложение (тот же id и файлы, что у пака `sr.general-x4v3-dn0`): Auto
выбирает его для чистых фото без загрузки — см. [ADR-0025](ADR-0025-effective-resolution.md).
Уровень 1.0 остаётся паком.

## Последствия

(+) Работает на всех бэкендах. (−) Нет плавного контроля денойза (сила эффекта остаётся плавной).

## Отклонённые альтернативы

- Интерполяция весов в рантайме: невозможна для Core ML. - Два прогона с блендом: 2× вычислений.
