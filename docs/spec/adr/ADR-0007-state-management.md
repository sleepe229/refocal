# ADR-0007: State management: Riverpod 3

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Нужны DI, асинхронные источники (очередь, события джоба), сессии редактора, тестируемость.

## Решение

Riverpod 3 с кодогенерацией. `editorSession` — family-провайдер на сессию; репозитории и движок — провайдеры с override в тестах.

## Последствия

(+) Меньше boilerplate, удобные тесты. (−) Кодогенерация в сборке.

## Отклонённые альтернативы

- Bloc: многословно, событийная модель не даёт выигрыша.
- Provider/GetX: слабее DI и тестируемость.
