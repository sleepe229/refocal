# ADR-0014: Scale strategy

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Пользователю нужны 1×/2×/4×/8×, а модели — ×4.

## Решение

- 4×: модель x4.
- 2×: x4 + area-downscale при выдаче полосы; «быстрый 2×» на T0: вход ×0.5 → x4.
- 1×: x4 + downscale ×4 (денойз/восстановление без увеличения).
- 8×: x4 → x4 → ↓2; только вход ≤ 1.5 МП и T2.
- RealESRGAN_x2plus — опциональный пак для T2 (позже).

## Последствия

(+) Один набор моделей. (−) 2×/1× тратят вычисления x4.

## Отклонённые альтернативы

- Отдельные x2/x1 модели для всех тиров: больше паков и конверсий.
