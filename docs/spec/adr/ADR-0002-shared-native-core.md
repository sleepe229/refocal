# ADR-0002: Shared native C++ core and refocal-cli

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Пиксельная логика (тайлинг, бленд, лица, кодеки, метаданные) нужна на двух платформах и в CI без устройств.

## Решение

Вся обработка — в общем C++20 core (`native/`, CMake). Платформенный код только за интерфейсами `PlatformCodec` (HEIC/AVIF), `PlatformSignals` (память, тепло) и `CoreMLBackend`. Из того же core собирается desktop CLI `refocal-cli` (Linux: ncnn CPU/Vulkan через lavapipe; macOS: Core ML) — для golden-тестов, perf и воспроизведения багов.

## Последствия

(+) Одна реализация, тестируется на desktop, Dart не касается пикселей.
(−) Нужна экспертиза C++, кросс-компиляция (NDK, Xcode), фаззинг.

## Отклонённые альтернативы

- Логика отдельно на Kotlin и Swift: две реализации, расхождения.
- Обработка в Dart: медленно, GC, лимиты памяти изолятов.
