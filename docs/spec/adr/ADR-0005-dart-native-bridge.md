# ADR-0005: Dart ↔ native bridge

- **Статус:** Accepted
- **Дата:** 2026-10-09

## Контекст

Нужен эффективный мост для управления джобами, прогресса и платформенных сервисов.

## Решение

- Пиксельный/ML-путь: `dart:ffi`, биндинги ffigen, плоский C ABI `enh_*` (appendix/enh.h). Параметры и события — JSON со схемой.
- События джоба: `Dart_PostCObject_DL` в native port сессии (`ReceivePort`), сообщение `[token, type, stage, done, total, payload_json]`. VM копирует сообщение, поэтому Dart ничего не освобождает. Пост в закрытый порт возвращает `false`, и ядро продолжает работу. Инициализация: `enh_dart_init(NativeApi.initializeApiDLData)`. `dart_api_dl.c` (BSD-3-Clause, Dart SDK) компилируется в core и записывается в `NOTICE`. *(Изменено по [S6](../../spikes/S6.md): было `NativeCallable.listener` + heap-JSON + `enh_free`.)*
- `NativeCallable.listener` для событий ядра **не используется**. Вызов после `close()` или после смерти изолята (hot restart; Android уничтожил FlutterEngine, а FGS держит процесс) — это abort всего процесса (`Callback invoked after it has been deleted`). `enh_event_cb` остаётся для C/C++-потребителей (`refocal-cli`, тесты).
- Повторное подключение к работающему джобу — `enh_job_set_port` / `enh_job_set_callback`. После возврата старый приёмник больше не получает событий.
- Протокол завершения: `enh_job_cancel` → ждать терминальное событие → `enh_job_destroy`. `destroy` работающего джоба блокирует вызывающий поток до конца текущего тайла (S6: до 91 мс при тайле 100 мс), поэтому на UI-изоляте его нельзя вызывать до терминального события. События с неизвестным токеном мост молча игнорирует.
- Коды возврата — `int32_t` (`typedef int32_t enh_status`), а не enum: ffigen не гарантирует размер enum, а сгенерированный `fromValue` бросает исключение на неизвестный код. В Dart неизвестный код отображается в `internal`.
- Все строки в событиях — валидный UTF-8. Ядро экранирует невалидные байты (U+FFFD): иначе VM отклоняет пост, и событие, в том числе терминальное, теряется.
- Платформенные сервисы (пикер, сохранение, FGS, тепло, память, share intake, жизненный цикл iOS): **Pigeon**.
- Native-библиотека — Flutter FFI plugin (CMake / podspec+xcframework). Flutter build hooks (native assets) — оценка в R1.3.

## Последствия

(+) Без копирования пикселей через каналы; типобезопасные платформенные API.
(+) Событийный канал переживает смерть изолята и не требует освобождения памяти в Dart. S6: 2 млн событий без утечек, задержка p99 ≤ 0.2 мс, 378 тыс. событий/с.
(−) Ручное управление памятью остаётся для `out_json` синхронных вызовов (`enh_free`).
(−) Зависимость от Dart API DL (`dart_api_dl.c`), версия которого привязана к SDK.

## Отклонено по итогам S6

- `NativeCallable.listener` для событий: падение процесса при смерти изолята, утечка всех сообщений, оставшихся в очереди при `close()` (S6: 10 002 из 10 002).

## Отклонённые альтернативы

- MethodChannel для пиксельного пути: копирование и сериализация.
- Dart-изоляты для тяжёлой работы: GC, память.
