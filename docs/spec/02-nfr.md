# 02. Нефункциональные требования

## 1. Тиры устройств

Все NFR по производительности задаются для **тиров**. Определение тиров — [ADR-0017](adr/ADR-0017-device-tiers.md), детали — [05 §6](05-inference-optimization.md#6-тиры-устройств).

| Тир | Критерии | Бэкенд | Тайл | Макс. выход | Модели |
|---|---|---|---|---|---|
| **T0** | RAM < 4 ГБ, или Vulkan в blocklist, или бенчмарк не прошёл | CPU (ncnn) | 128 | 8 МП | compact SR; face — CPU, ≤ 1 лица или выкл. |
| **T1** | RAM 4–6 ГБ, рабочий GPU/ANE | Vulkan / Core ML | 256 | 16 МП | compact SR, GFPGAN fp16 |
| **T2** | RAM ≥ 8 ГБ, SoC ≥ Snapdragon 8 Gen 2 / Dimensity 9200 / Apple A16 | Vulkan / Core ML (+NPU в 1.3) | 256–512 | 48–100 МП (потоково) | + x4plus, CodeFormer, 8× |

Значения NFR-PERF-004 — `[оценка → S1b]`, NFR-PERF-001/002 — `[оценка → S2, S4]`. Фиксируются по итогам спайков.

**NFR-PERF-003 по итогам [S1](../spikes/S1.md):** GFPGAN — 398 GFLOPs на лицо. Оценка T2 0.15–0.4 с и T1 0.4–1.5 с укладывается в лимиты. На **T0** CPU выходит 10–15 с при лимите 10 с, а память ~0.6 ГБ при бюджете 600 МБ. Поэтому на T0 восстановление лиц **выключено по умолчанию** и включается как «экспериментальное» при свободной памяти ≥ 1.2 ГБ. Замеры на устройствах — S1b.
