1. ~~R1 (20)~~ → 10 после S1: конверсия и fp16 решены перезаписью графа; мобильные замеры — S1b.
2. **R3** (16) — GPU-драйверы → S3, crash sentinel в 0.1.
3. **R12** (16) — устойчивость команды → governance с 0.5.
4. **R2, R5, R9, R10, R14, R15** (12).
