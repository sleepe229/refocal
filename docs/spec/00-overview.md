# 00. Обзор и видение

## 1. Проблема

Люди хранят тысячи фотографий плохого качества: снимки со старых телефонов, пережатые мессенджерами, сканы бумажных фото, кадры из видео, скриншоты. Существующие решения:

| Решение | Проблема |
|---|---|
| **Remini** и клоны (YouCam Enhance, EnhanceFox, Picwand) | Агрессивные недельные подписки ($3–10/нед.), реклама, загрузка фото на сервер, «чужое лицо» после обработки (выдуманные глаза, уши, похудение тела) |
| **PhotoDirector, Picsart** | Пейволлы, водяные знаки, облако |
| **Samsung Remaster, Google Photos** | Привязаны к бренду/аккаунту/подписке, нет ручного контроля |
| **SuperImage** (FOSS) | Только Android, только апскейл (нет лиц), медленно (≈3 мин на 1080p на Snapdragon 855), GPL-3, **заброшен (архив с 11.2023)** |
| **Upscayl** (FOSS) | Только десктоп, нужна видеокарта |

**Ниша:** живого open-source кросс-платформенного мобильного приложения с восстановлением лиц, работающего полностью офлайн, нет.

## 2. Видение

> Бесплатный, приватный и честный улучшатель фото: всё на телефоне, никаких подписок, ты контролируешь, насколько ИИ меняет снимок.

## 3. Позиционирование

| Ось | Remini | Refocal |
|---|---|---|
| Цена | Подписка | Бесплатно, open-source |
| Приватность | Загрузка на сервер | 100% на устройстве, без сети по умолчанию |
| Контроль | One-tap, «как получится» | Сила эффекта, сила лица, регион, отдельные лица |
| Честность | «Восстановленное фото» | Явная маркировка «изменено ИИ», предупреждение об изменении черт лица |
| Скорость | Секунды (облачные GPU) | Секунды–минуты, зависит от телефона; прогресс и ETA |

## 4. Цели

| ID | Цель | Мера успеха |
|---|---|---|
| G-1 | Качество, сопоставимое с открытыми SOTA-моделями на устройстве | Golden-набор: NR-IQA не хуже эталона PyTorch более чем на 2% |
| G-2 | Работа на большинстве устройств последних 5 лет | Тир T0 работает на 3 ГБ RAM без падений |
| G-3 | Полная приватность | 0 сетевых запросов без явного действия пользователя (проверяется тестом) |
| G-4 | Честность | Маркер ИИ по умолчанию, ArcFace-гейт идентичности ≥ 0.95 |
| G-5 | Устойчивый OSS-проект | Сборки в GitHub Releases и F-Droid (воспроизводимая); Google Play и App Store — по решению владельца (Q-06) |

## 5. Не-цели (явно вне рамок)

- Облачная обработка, свой сервер, аккаунты, синхронизация.
- Монетизация: подписки, реклама, платные функции.
- Генерация изображений «с нуля», AI-аватары, headshots.
- Face swap, «раздевание», изменение формы тела, бьютификация, омоложение/старение. Запрещены политикой проекта (см. [15](15-ethics-responsible-ai.md)).
- Обработка видео (может появиться после 2.0 отдельным решением).
- Десктопная версия до 2.0 (CLI `refocal-cli` существует как инструмент разработки).
- Полноценный фоторедактор (кадрирование, фильтры, кривые) — только минимальный поворот/кадрирование при необходимости.

## 6. Принципы

1. **On-device first.** Никаких серверов. Сеть — только для скачивания моделей по явному действию.
2. **Честность важнее «вау».** По умолчанию — умеренные настройки лица; результат никогда не называется «оригиналом».
3. **Приватность по умолчанию.** Нет телеметрии; GPS удаляется при отправке; нет широких разрешений на галерею.
4. **Деградация вместо падения.** Нехватка памяти, плохой драйвер, перегрев — снижаем тайл/бэкенд/масштаб, а не падаем.
5. **Прозрачность.** Видно, какая модель, какой бэкенд, почему выбран такой режим (Auto объясняет решения).
6. **Лицензионная чистота.** Ядро — только permissive-лицензии; NC-модели — опционально, с явным согласием.
7. **Одна реализация.** Вся обработка пикселей — в общем C++ core для обеих платформ.

## 8. Ключевые сценарии

1. **Быстрое улучшение:** выбрать фото → Auto → сравнить → сохранить. ≤ 3 тапа.
2. **Старое фото с лицами:** выбрать → «Восстановление лиц» → подстроить силу лица → сохранить.
3. **Пакет:** выбрать 30 фото → пресет → очередь в фоне → уведомление о готовности.
4. **Из другого приложения:** «Поделиться» → Refocal → обработка → вернуть/сохранить.
5. **Энтузиаст:** скачать пак HQ-модели, принять лицензию, выбрать модель вручную.

## 9. Метрики успеха (без телеметрии)

Телеметрии нет, поэтому успех измеряется косвенно:

- рейтинг и отзывы (F-Droid, сторы — при публикации; цель ≥ 4.5);
- звёзды и форки GitHub, число контрибьюторов;
- доля issue типа «плохой результат» к общему числу;
- регрессии качества по golden-набору в CI (цель — 0 незамеченных);
- crash-free по отчётам бета-тестеров; при публикации в сторах — Play Vitals / App Store Connect (без SDK): ≥ 99.5%.
