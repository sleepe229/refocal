# 01. Функциональные требования

Конвенции ID и приоритетов — см. [README](README.md#конвенции). Тестовые ID (TEST-*) определены в [10](10-testing-qa.md).

## 1. Обзор функций

```
Ввод (пикер / share / файл)
   └─► Анализ (лица, шум, размер) ─► Выбор режима/параметров (Auto или вручную)
          └─► Обработка (очередь, прогресс, отмена, пауза, фон)
                 └─► Сравнение (слайдер, удержание, side-by-side, зум)
                        └─► Фильтр (опц.: «Пастель», «Блики»)
                               └─► Экспорт (формат, метаданные, сохранение/поделиться)
                               └─► История (рецепт, повтор)
```

## 3. Обработка (ENH)

### 3.1 Режимы

| Режим | Что делает | Модели | Релиз |
|---|---|---|---|
| **Auto** | Анализирует фото и выбирает масштаб, денойз, восстановление лиц; объясняет решение | все доступные | R0.2 |
| **Upscale** | Увеличение 2× / 4× / 8× | SR | R0.1 |
| **Face restore** | Восстановление лиц, фон — лёгкий апскейл или без изменений | детектор + face-модель (+SR) | R0.2 |
| **Denoise / Deblur** | Шумоподавление без изменения размера (1×) или с апскейлом | SR (уровни денойза) | R0.2 |
| **Old photo** | Лица + SR + удаление царапин (1.1) + колоризация (1.2) | несколько | R0.2 (базовый), R1.1, R1.2 |
| **Low-light** | Осветление + денойз | см. 04 (спайк) | R1.1 |
| **Anime/Art** | SR, обученная на рисунках | anime_6B | R0.5 |

## 8а. Фильтр (LOOK)

Поправка 2026-10-20 (0.8), см. 00 §5 и ADR-0012. Фильтр глобальный: одна аффинная цветовая матрица на весь кадр и наложение, привязанное к краям кадра; ничего не зависит от положения лиц (15 §3).

| ID | Требование | Приоритет | Релиз | Критерий приёмки | Трассировка |
