# Приложение D. Журнал решений по открытым вопросам

Решения приняты 2026-10-09 по поручению владельца проекта. Вопросы о публикации в Google Play и App Store **остаются за владельцем** (Q-06, Q-07b).

## Решено

| ID | Вопрос | Решение | Обоснование | Влияет на |
|---|---|---|---|---|
| Q-01 | Название, бренд, идентификаторы | **Refocal.** `applicationId` / bundle id `io.github.refocal.app`, URL-схема `refocal://`, GitHub-организация `refocal`, сайт `refocal.github.io`. Подробно — [brand.md](brand.md) | Название не занято на GitHub, F-Droid и в выдаче приложений (проверено 2026-10-09). Домен на GitHub Pages ничего не стоит и не требует покупки | Все документы, сторы, 12 §8 |
| Q-02 | Минимальная iOS и iPad | **iOS 16.** iPad в 1.0 работает как увеличенный iPhone (адаптивная вёрстка), полноценный планшетный UX — в 1.2 | iOS 16 даёт стабильный Core ML mlprogram и покрывает ~95% активных устройств | COMP-IOS-001, NFR-COMPAT-004 |
| Q-03 | ABI Android | **Только arm64-v8a** (+ x86_64 для эмулятора и CI) | 32-битные устройства почти все ниже T0; экономия ~40% размера native-библиотек | NFR-COMPAT-003, NFR-SIZE-001 |
| Q-04 | Хостинг NC-весов | **Зеркало сконвертированных весов** в организации `refocal` на Hugging Face и в GitHub Releases, с полным текстом лицензии, атрибуцией и ссылкой на upstream. Публикация — **только после положительного вывода S9** | Upstream не публикует ncnn/Core ML-форматы; S-Lab и Apache с NC-компонентами допускают некоммерческое распространение с уведомлением | ADR-0011, ADR-0022, 12 §3 |
| Q-05 | Ключ подписи манифеста | Пока мейнтейнер один, он же хранитель ключа. Резервная копия — зашифрованная (`age`) на офлайн-носителе в отдельном месте. Второй хранитель — первый соавтор с правами релиза, **обязательно до 1.0** | Реалистично для соло-проекта; bus factor закрывается до GA (OPS-GOV-005) | SEC-SUP-005 |
| Q-07a | Каналы публикации без сторов | **GitHub Releases (APK) и F-Droid** с 0.5. Закрытая бета 0.3 раздаётся APK через GitHub (pre-release) | Не требует аккаунтов и денег, соответствует FOSS-позиционированию | 11 §4, 13 |
| Q-08 | Языки | **en + ru** в 0.3; Weblate (бесплатный хостинг для libre-проектов) с 0.5 | Основная аудитория и мейнтейнер — русскоязычные, английский нужен для OSS | NFR-L10N-002/005 |
| Q-09 | Отчёты о падениях | **Не делаем в 1.x**: ни opt-in, ни по умолчанию. Диагностика — экспорт локального лога пользователем и шаблон issue | У проекта нет серверов, а GlitchTip требует сопровождения. «Data Not Collected» во всех декларациях, никаких спорных моментов в F-Droid. Пересмотр после 1.0 | ADR-0020, 07 §6, 08 |
| Q-10 | Донаты | **GitHub Sponsors + Liberapay**, подключаются после вывода S9. Формулировка: «поддержка разработки открытого кода»; без платных функций и без привязки к NC-моделям | Liberapay — FOSS-дружественная площадка без комиссии; отсутствие встречного предоставления снижает риск трактовки как коммерции | 12 §3, R9 |
| Q-11 | Язык документации | ТЗ — RU; README, CONTRIBUTING, код, комментарии, ADR-заголовки — EN; README дублируется на RU (`README.ru.md`) | Международное OSS-сообщество при русскоязычной основной аудитории | README |
| Q-12 | HEIC на Android | **Да**, при поддержке устройства, ≤ 50 МП; если не поддерживается, пункт скрыт | Платформенный энкодер, лицензионных рисков нет | FR-EXP-002 |
| Q-13 | Аниме-модель | **В 0.5** | Та же архитектура RRDBNet, конверсия почти бесплатная | FR-ENH-016 |
| Q-14 | Устройства для тестов | Старт: собственные устройства + эмуляторы/симуляторы + community-матрица (perf-отчёты в issue). Докупаем **б/у T0-устройства** (Redmi 9A, iPhone SE 2, дешёвые) как самые проблемные. Облачные фермы — только бесплатные лимиты (Firebase Test Lab spark, AWS Device Farm trial) | Минимальный бюджет; T0 — главный источник падений | 10 §10, device-matrix |
| Q-15 | `refocal-cli` для пользователей | **Только инструмент разработки** до 2.0. Бинарники публикуются в Releases «как есть», без поддержки | Нет ресурсов на поддержку desktop | ADR-0002 |
| Q-16 | Диск и квоты | До **~600 МБ** временного места на джоб (192 МП); inbox **1 ГБ / 7 дней**, LRU; пользователь меняет в настройках | Укладывается в типичные 10+ ГБ свободного места; проверка места перед стартом | NFR-SIZE-004/006 |

## Остаётся за владельцем

| ID | Вопрос | Что нужно решить | Что зависит |
|---|---|---|---|
| Q-06 | Аккаунты сторов | Публиковать ли в Google Play ($25 разово) и App Store ($99/год); на кого оформлять аккаунты (физлицо или организация); кто владеет ключами подписи сторов | Флейвор `play`, Fastlane, Data Safety / Privacy Label, COMP-AND-008/009, COMP-IOS-008…011 |
| Q-07b | Сроки сторов | Если публиковать: Play open testing с 0.5, App Store с 1.0 (план по умолчанию в ТЗ) или иначе | 13, 11 §4 |

**Важно для iOS.** Без App Store установить приложение на iPhone можно только тремя путями: TestFlight (тоже нужен платный аккаунт), сборка из исходников через Xcode (бесплатный аккаунт, переустановка раз в 7 дней) или альтернативные магазины ЕС по DMA (тоже нужен аккаунт разработчика). То есть iOS-версия для обычных пользователей фактически требует решения по Q-06. Пока его нет, iOS-часть разрабатывается и тестируется, а распространяется сборкой из исходников.
