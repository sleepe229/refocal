# Приложение E. Бренд: Refocal

## 1. Название

**Refocal** (произносится «ри-фо́-кал»).

- **Смысл:** *re-* (снова) + *focal* (фокусный, в фокусе): «вернуть фото в фокус». Слово короткое, читается одинаково на английском и русском, его нет в словарях, поэтому оно хорошо находится поиском.
- **Проверка (2026-10-09):** на GitHub пользователь/организация `refocal` свободны; пакет `io.github.refocal` в F-Droid отсутствует; приложений с таким названием в поисковой выдаче нет. Ближайшее созвучие — Nokia Refocus (камера Lumia, 2013–2014, снята с поддержки).
- **До публикации в сторах** нужна формальная проверка товарных знаков (EUIPO, USPTO, Роспатент, класс 9). Если публикации в сторах не будет, достаточно уже сделанной проверки.

## 3. Слоган

- EN: **"Bring your photos back into focus. On your phone."**
- RU: **«Верните фото в фокус. Прямо на телефоне.»**
- Короткий вариант для бейджей: *Private. Free. On-device.* / *Приватно. Бесплатно. На устройстве.*

## 4. Голос и тон

- Спокойный, честный, технически грамотный, без хайпа.
- Не обещаем «восстановить как было»: говорим «улучшить», «сделать чётче», «ИИ дорисовывает детали».
- Приватность — факт, а не маркетинг: «Фото не покидают телефон».
- Без восклицательных знаков и без «магии» в формулировках.

## 5. Визуальный стиль

### Логотип и иконка

- **Концепция:** кольцо фокусировки объектива (окружность с насечками) и внутри квадратная пиксельная сетка 3×3, которая к центру переходит в чёткий круг: «пиксели → фокус».
- **Иконка приложения:** знак белым на фоне фирменного градиента. Adaptive icon (Android) с отдельными слоями foreground/background и монохромным слоем для тематических иконок Android 13+. iOS: светлый, тёмный и tinted варианты (iOS 18+).
- **Минимальный размер знака:** 16 px (favicon) в упрощённом варианте, без насечек.

### Цвета

| Токен | Hex | Назначение |
|---|---|---|
| `brand.primary` | `#3D5AFE` | Основной (индиго), кнопки, акценты |
| `brand.secondary` | `#00BFA5` | Вторичный (бирюза), прогресс, «после» на слайдере |
| `brand.gradient` | `#3D5AFE → #00BFA5` (135°) | Фон иконки, онбординг |
| `neutral.900` | `#111318` | Текст (светлая тема), фон (тёмная) |
| `neutral.50` | `#F7F8FA` | Фон (светлая тема) |
| `warn` | `#FFB300` | Предупреждения ИИ, fallback-баннеры |
| `error` | `#E53935` | Ошибки |

Все пары текст/фон проверяются на контраст ≥ 4.5:1 (A11Y-GEN-003). Material 3 dynamic color (Android 12+) по умолчанию **выключен**, чтобы слайдер «до/после» всегда был узнаваем. Включается в настройках.

### Типографика

- Системные шрифты: Roboto / SF Pro, через тему Flutter. Свои шрифты не встраиваем, это экономит размер.
- Цифры (разрешение, проценты, ETA) — `FontFeature.tabularFigures()`.
