# Спайк S8: воспроизводимая сборка Android (F-Droid) с native ncnn и Flutter-сабмодулем

| | |
|---|---|
| Дата | 2026-10-12 |
| Риск | [R8](../spec/14-risks.md): F-Droid — невоспроизводимая сборка с native и Flutter |
| Код | [`tools/rebuilder/`](../../tools/rebuilder/) (Dockerfile, `s8.sh`), скелет монорепо (`app/`, `packages/`, `native/`) |
| Вердикт | **GO.** Release APK флейвора `fdroid` побайтово воспроизводится при разных пути, пользователе, TZ, локали, umask, hostname, числе CPU и времени. Подпись разработчика переносится на сборку «сервера» и проверяется, если APK подписан Gradle (`signingConfig`) или `apksigner --alignment-preserved`. Проверка настоящим `fdroid build` — S8b |

## 1. Итог

1. **Воспроизводимость есть.** Две сборки с нуля в восьми различающихся условиях дали один и тот же APK: sha256 `9e10efab…`, 20 610 604 байта. Детерминированы:
   - `libenh.so` (ncnn + glslang + шейдеры SPIR-V, которые компилируются при сборке);
   - Dart AOT (`libapp.so`);
   - DEX после R8 и ресурсы.

   Путей сборки в APK нет.
2. **Подписывать можно только двумя способами.** F-Droid копирует нашу подпись на свою неподписанную сборку (`apksigcopier`). Подпись переносится, если APK подписал Gradle (`signingConfig`) или `apksigner sign --alignment-preserved`. Обычный `apksigner sign` перекладывает ZIP: смещения 9 записей сдвигаются, и перенесённая подпись даёт `CHUNKED_SHA512 digest mismatch`. Поэтому подписанный APK после Gradle больше не трогаем: ни `zipalign`, ни переподписи.
3. **Найдены и исправлены три настройки скелета, без которых результат был бы другим:**
   - Flutter Gradle plugin подменяет `abiFilters` приложения, и в APK попадали `libenh.so` для armeabi-v7a и x86_64: +7.3 МБ, 27.9 → 20.6 МБ;
   - AGP пишет git-ревизию в `META-INF/version-control-info.textproto`;
   - AGP 9.1 неявно докачивает `build-tools;36.0.0`.
4. **Размер и время.** APK 20.6 МБ с ncnn и Vulkan укладывается в цель 0.1 (≤ 30 МБ). Сборка с нуля (Gradle) занимает 4.7 мин на 12 ядрах и 8.6 мин на 4 ядрах.

## 2. Что собиралось

Скелет монорепо по 03 §3, тот же, что пойдёт в 0.1:

- `app/` — Flutter 3.47.7 (Dart 3.13.5), флейворы `play`/`fdroid`, `minSdk 29`, `targetSdk 36`, `applicationId io.github.refocal.app`. Экран показывает `enh_version()` и `enh_device_probe()`.
- `packages/refocal_ffi` — FFI-плагин. AGP `externalNativeBuild` собирает корневой `native/CMakeLists.txt`, Dart-биндинги генерирует ffigen из `native/include/enh.h`.
- `native/` — `libenh.so` (C++20) со статически слинкованным **ncnn 20260526** (сабмодуль) с Vulkan: glslang и компиляция SPIR-V-шейдеров идут во время сборки.
- `packages/refocal_core` (чистый Dart) и `packages/refocal_platform` (Kotlin/Swift-плагин из шаблона).
- `flutter/` — Flutter SDK сабмодулем на `3.47.7` (`abaf9c52`).

**Тулчейн** (`tools/rebuilder/Dockerfile`), всё закреплено:

| Компонент | Версия / пин |
|---|---|
| База | `debian:trixie-slim@sha256:a29215f6…` |
| JDK | OpenJDK 21 (Debian) |
| Android cmdline-tools | 23.0 (`commandlinetools-linux-16111833`, sha1 проверяется) |
| SDK | `platforms;android-36` r02, `build-tools;36.0.0`, `ndk;28.2.13676358` (r28c), `cmake;3.31.6`. sdkmanager сверяет sha1 по `repository2-3.xml` |
| Gradle / AGP / Kotlin | 9.3.1 / 9.1.0 / 2.4.0 (из шаблона Flutter 3.47.7) |
| Проверка | `apksigcopier`, `apksigner` 36.0.0, `diffoscope-minimal` |

SDK в образе **read-only** для сборщика. Поэтому любая попытка AGP докачать компонент «молча» превращается в ошибку: так нашёлся неявный `build-tools;36.0.0`, см. §4.

## 3. Методика

`tools/rebuilder/s8.sh`:

1. **Снимок исходников** — отслеживаемые git-файлы репозитория и сабмодулей (`git ls-files --recurse-submodules`) без кэшей хоста. Flutter SDK внутри контейнера клонируется из локального зеркала на закреплённый коммит: утилите `flutter` нужна git-история для определения версии.
2. **Сборка A** («разработчик») и **сборка B** («сервер F-Droid»): `flutter build apk --release --flavor fdroid`. Каждая в отдельном контейнере, с нуля: свежие `pub`/Gradle-кэши и артефакты движка Flutter.

| Параметр | A | B |
|---|---|---|
| Путь исходников | `/home/builder/refocal` | `/tmp/fdroid-home/build/io.github.refocal.app` |
| UID:GID | 1000:1000 | 4242:4242 |
| TZ / LANG | UTC / C.UTF-8 | Asia/Tokyo / ru_RU.UTF-8 |
| umask | 022 | 077 |
| hostname / CPU | dev-box / 12 | fdroid-bs / 4 |
| Время | T | T + ≈ 6 мин |

3. Сравнение: `sha256`. При различии запускается `diffoscope`.
4. **Проверка F-Droid:** подпись APK разработчика копируется на неподписанную сборку сервера (`apksigcopier copy`) и проверяется `apksigner verify`. Сравниваются три способа получить подписанный APK разработчика:
   - `apksigner sign` поверх A;
   - `apksigner sign --alignment-preserved`;
   - **сборка C** — как A, но подпись ставит Gradle (`signingConfig` из `key.properties`); так будет подписывать `release.yml`.

## 4. Результаты

Финальная конфигурация: коммит скелета, `disable-abi-filtering`, `vcsInfo` отключён.

| Сборка | Условия | Время (Gradle), с | Размер, байт | sha256 |
|---|---|---|---|---|
| A (неподписанная) | см. §3 | 285 | 20 610 604 | `9e10efabe137c042…ee18ca1069` |
| B (неподписанная) | см. §3 | 519 (4 CPU; в логе `518,8s` — локаль ru_RU действительно применилась) | 20 610 604 | `9e10efabe137c042…ee18ca1069` |
| C (подпись Gradle, тестовый ключ) | как A + `key.properties` | 299 | 20 639 857 | — |

**Перенос подписи** (`apksigcopier copy <signed> B.apk out.apk && apksigner verify out.apk`):

| Подписанный APK разработчика | Результат |
|---|---|
| `apksigner sign A.apk` (по умолчанию) | ❌ `APK Signature Scheme v3 signer #1: APK integrity check failed. CHUNKED_SHA512 digest mismatch` — у 9 записей ZIP изменились смещения |
| `apksigner sign --alignment-preserved A.apk` | ✅ verifies |
| C — подписан Gradle `signingConfig` | ✅ verifies (схема v2; v1 не нужна при `minSdk 29`) |

**Прочее:**
- `zipalign -c -P 16 4` проходит: `.so` выровнены по страницам 16 КБ (устройства Android 15+).
- В APK нет строк `/home/builder` и `/tmp/fdroid-home`.
- `libenh.so` stripped; в ELF-заметке `built by NDK r28c (13676358)`.
- Промежуточный прогон на конфигурации до исправлений ABI и vcsInfo тоже был побайтово воспроизводимым (`ff565232…`, 20 610 689 байт). То есть детерминизм не держится на этих правках: они меняют только состав APK.

## 5. Находки и исправления

| # | Находка | Последствие | Исправление |
|---|---|---|---|
| 1 | `apksigner sign` по умолчанию меняет расположение записей ZIP | Подпись не переносится на сборку F-Droid → F-Droid подписал бы APK своим ключом, и пользователи не смогли бы обновляться между каналами GitHub ↔ F-Droid | Release подписывается Gradle `signingConfig` (`key.properties` в `release.yml`); если нужна внешняя подпись — только `apksigner --alignment-preserved`; после подписи ничего не трогать |
| 2 | Flutter Gradle plugin в `configureAbiWithoutSplits` очищает `defaultConfig.ndk.abiFilters` и ставит свои ABI. Фильтр приложения в `refocal_ffi` не попадает | В APK лишние `libenh.so` armeabi-v7a и x86_64 (+7.3 МБ), Q-03 нарушен | `disable-abi-filtering=true` в `app/android/gradle.properties`; ABI arm64-v8a + x86_64 (эмулятор, CI), в release x86_64 исключается `androidComponents.onVariants` |
| 3 | AGP ≥ 8.3 пишет `META-INF/version-control-info.textproto` с git-ревизией | Сборки из tar, shallow или грязного клона дают другой APK | `buildTypes.release { vcsInfo { include = false } }` |
| 4 | AGP 9.1 требует `build-tools;36.0.0` и пытается его докачать | Неявная зависимость тулчейна | SDK в образе read-only, пин `build-tools;36.0.0` |
| 5 | sdkmanager распаковывает исполняемые файлы с правами `rwxr--r--` | `cmake: Permission denied` у непривилегированного сборщика | `chmod -R a+rX $ANDROID_HOME` в Dockerfile |
| 6 | Периодические сбросы TLS к `dl.google.com` и Maven Central (`Remote host terminated the handshake`) | Падение сборки, к детерминизму не относится | Повтор до 3 раз в `s8.sh`. Для 0.5 — Gradle dependency verification (`verification-metadata.xml`), чтобы докачка из сети была ещё и проверяемой |

## 6. Ограничения

- Обе сборки идут в **одном образе**. Сервер F-Droid ставит SDK/NDK своими средствами и может использовать другой JDK. Тулчейн-независимость (другой JDK, другой хост-дистрибутив) здесь не проверена. Окончательная проверка — сборка `fdroid build` из рецепта fdroiddata на первом теге (S8b, до 0.5).
- Сборки из tar-снимка, а не из git-клона. Единственное найденное отличие такого рода (`version-control-info`) отключено.
- Приложение — скелет. Реальные ассеты, Pigeon-код, больше native-кода и модели в бандле могут добавить источники недетерминизма. Поэтому проверка воспроизводимости должна регулярно идти в CI (nightly), а не быть разовой.
- Не проверено, нужен ли `-ffile-prefix-map` в `native/CMakeLists.txt`: путей нет и в stripped `.so`, и в итоговом APK, но отдельного прогона без флага не было. Флаг оставлен как дешёвая страховка.
- iOS не входит в S8: F-Droid только Android, а воспроизводимость IPA не требуется.

## 7. Предлагаемые изменения в ТЗ

1. **08 COMP-FDR-004:** уточнить механизм. Release APK подписывается Gradle `signingConfig`, после подписи не меняется; `apksigner` — только с `--alignment-preserved`. F-Droid проверяет перенос подписи (`apksigcopier`). Статус «проверено на скелете (S8)».
2. **11 §1 / OPS-CI:**
   - OPS-CI-003: тулчейн Android закреплён в `tools/rebuilder/Dockerfile` (источник правды: SDK/NDK/CMake/build-tools/JDK), `android`-джоба `pr.yml` собирает в этом образе;

3. **11 §3 Подпись:** строка «Android (GitHub/F-Droid)» — подпись через Gradle `signingConfig` в `release.yml`, без последующих `zipalign` и переподписи.
4. **03 §3 Монорепо:** добавить корневой `pubspec.yaml` (pub workspace), `analysis_options.yaml`, `tools/rebuilder/`. **03 §12 Флейворы:** ABI arm64-v8a (+ x86_64 вне release), `disable-abi-filtering`, `vcsInfo` выключен.
5. **10:** новый TEST-COMP-005 — воспроизводимость: две сборки `fdroid` в разных окружениях побайтово равны, а подпись Gradle-сборки переносится на вторую (`s8.sh`, nightly).

7. **13:** статус S8, а также веха M0 «монорепо-скелет и `pr.yml` работают»: локально проходят все шаги `pr.yml`, но на GitHub-раннере `pr.yml` ещё не запускался.
